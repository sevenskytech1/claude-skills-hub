What are Claude Skills?

Claude Skills are predefined sets of instructions, tools, and contexts that you can give to Claude. For n8n automation, this means defining n8n's specific data structures (like the `items` array), expression syntax, and best practices so the AI generates code and logic that works perfectly inside the n8n environment on the first try.

Why use Skills for n8n?

  • Flawless Code Nodes: Generate JavaScript or Python scripts that correctly handle n8n's specific `items[0].json` data structure.
  • Complex Data Transformation: Instantly write logic to flatten nested JSON, map arrays, or format dates for downstream APIs.
  • Robust Error Handling: Design workflows that gracefully handle API failures, timeouts, and webhook errors using n8n's Error Trigger nodes.

Practical SKILL.md Example

Below is a powerful skill for n8n automation. It ensures Claude writes code that is fully compatible with n8n's sandbox environment and follows workflow best practices.

# Skill: n8n Workflow & Code Node Architect ## Description Assists automation engineers in designing n8n workflows, writing complex JavaScript/Python for Code nodes, and troubleshooting webhook JSON payloads. ## Instructions 1. When asked to design a workflow, outline the trigger, core nodes, and error handling steps. 2. When writing Code node scripts, ensure they handle n8n's specific item structure (e.g., iterating over `items` and returning an array of objects). 3. Provide clear instructions on how to map data between nodes using n8n's expression syntax (e.g., `{{ $json.fieldName }}`). 4. Suggest best practices for error handling (e.g., using the Error Trigger node or "Continue On Fail" settings). ## Constraints - Always use n8n's native expression syntax for simple data mapping; only use the Code node for complex logic. - Ensure all JavaScript code is compatible with n8n's sandbox environment (Node.js). - NEVER hardcode API keys; always instruct the user to use n8n Credentials. - Return data in the exact format n8n expects: an array of objects (e.g., `return [{ json: { ... } }]`).

Installation Guide

Set up this automation skill in your workspace in three simple steps:

  1. Create a folder in your project root named .claude/skills/ (or keep it in your automation documentation folder).
  2. Create a file named n8n-architect.md and paste the code from the example above.
  3. When building a new automation, simply say: "Use the n8n Architect skill to write a Code node that transforms this webhook payload..."

Example Prompts

"Activate the n8n Workflow Architect skill. I need to build a workflow that triggers on a new Stripe payment, formats the customer data, and sends a Slack notification. Outline the nodes and write the Code node script for the data formatting."

Frequently Asked Questions

How do I connect Claude to n8n?

You can use n8n's native Anthropic node (or the HTTP Request node) to send prompts to Claude's API. You can pass dynamic data from previous nodes into the prompt using n8n expressions like {{ $json.customerName }}.

Can Claude execute my n8n workflows?

No. Claude Skills help you write the logic and code for your workflows, but you must copy that code into your n8n instance and execute it there. Claude does not have direct access to run your n8n server.

Does this work for self-hosted n8n?

Absolutely. The workflow logic, Code node scripts, and expression syntax are identical whether you are using n8n Cloud or a self-hosted Docker instance.
