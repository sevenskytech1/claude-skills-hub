What are Claude Skills?

Claude Skills are predefined sets of instructions, tools, and contexts that you can give to Claude. For designers, this means defining your brand's design system rules, accessibility standards, and preferred coding frameworks so the AI provides feedback and assets that align perfectly with your team's visual language.

Why use Skills for Design?

  • Automate Design Systems: Instantly generate JSON/CSS design tokens, typography scales, and color palettes.
  • Accessibility Audits: Get immediate, structured feedback on contrast ratios and WCAG 2.1 compliance.
  • Design-to-Code: Seamlessly translate UI concepts into Tailwind CSS, HTML, or React components.

Practical SKILL.md Example

Below is a powerful skill for UI/UX workflows. It ensures Claude prioritizes accessibility, structures design tokens correctly, and provides actionable design feedback.

# Skill: UI/UX Design System & Feedback Assistant ## Description Assists designers in creating design tokens, critiquing UI layouts for accessibility, and generating CSS/Tailwind code for design systems. ## Instructions 1. When asked to critique a UI, evaluate it based on visual hierarchy, contrast ratios (WCAG), and user flow. 2. When generating design tokens, output them in JSON or CSS variables format. 3. Suggest accessible color combinations and typography scales (using a modular scale like 1.25). 4. If requested, translate design concepts into clean HTML/CSS or Tailwind utility classes. ## Constraints - Always prioritize accessibility (WCAG 2.1 AA standards) in color and typography suggestions. - Do not generate raster images; instead, provide detailed prompts for image generators or write SVG code. - Keep design feedback constructive, specific, and actionable.

Installation Guide

Set up this design skill in your workspace in three simple steps:

  1. Create a folder in your project root named .claude/skills/ (or keep it in your design documentation folder).
  2. Create a file named ui-ux-assistant.md and paste the code from the example above.
  3. When working on a new interface, simply say: "Use the UI/UX Assistant skill to review this wireframe description and suggest a color palette..."

Example Prompts

"Activate the UI/UX Assistant skill. I am designing a dashboard for a fintech app. Please generate a primary and secondary color palette in JSON format, ensuring all text/background combinations meet WCAG AA standards."

"Using the Design System skill, critique this landing page layout: [describe layout]. Focus on visual hierarchy and suggest improvements for mobile responsiveness."

Frequently Asked Questions

Can Claude generate actual images or icons?

Claude is a text-based AI, so it cannot generate raster images (like PNGs or JPGs). However, it can write highly detailed prompts for Midjourney or DALL-E, generate scalable SVG code for icons, or create CSS-based illustrations.

How does this integrate with Figma?

While Claude doesn't plug directly into Figma's canvas, it is incredible at writing Figma Plugin code (using TypeScript) or generating the exact design tokens (JSON) that you can import into Figma using plugins like Tokens Studio.

Can it check my actual color contrast ratios?

Yes! If you provide the HEX codes for your foreground and background colors, Claude can calculate the contrast ratio and tell you if it passes WCAG AA or AAA standards.
